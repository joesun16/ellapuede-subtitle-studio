# 0.15.1 检查方法与限制

本版新增框选预览播放、暂停和连续拖动；修复低分断行、缺行复核覆盖已验证文字，以及把同一行的末尾杂点误当成另一条字幕行的问题。复核按原视频 PTS 读取画面；不能用语义猜测补写对白。

## 公开可复现的检查

255 项源码回归覆盖真实换字、数字、否定词、标点、空白边界、缺上行、后缀误恢复、顺序解码回退、预览播放及取消等行为。测试使用可公开的合成场景。Mac 和 Windows 的构建流程均运行相同回归；安装包还检查内置多语 OCR、连续预览、反向定位、实际帧时间、同名 SRT/ASS 和连续任务。Windows CI 同时检查安装与卸载。

`tools/reference_benchmark.py` 可读取你有权使用的视频参考字幕（SRT/ASS/JSON），在本机比较每条文字与时间轴。默认只归一化 Unicode NFC 和空白；保留大小写、重音、标点、数字差异，分别报告漏句、额外条目、字符编辑率及一致文本的起止误差。参考字幕也可能不同于烧录画面，应逐帧核验，不能把任何参考差异直接解释成 OCR 错误。

## 质量和性能边界

当前仍是公测。泰语及复杂多行字幕仍可能缺行、错字或拆条；反光和与对白同位置、同字号的场景文字仍可能误收。没有证据可以承诺任何语言的零错误识别。私人样片、逐条对白、画面及详细测试数据不随公开仓库发布。

三个模式调整资源预算，不降低对白识别与复核规则。预览可以丢弃过时画面请求来追赶播放时钟，正式提取不能据此跳过字幕帧。代码减少了无用解码、重复视频打开和图像转换，但实际速度仍取决于视频、语言、模型和设备，不能承诺每一种语言或平台都会更快。

Windows CI 通过安装与功能测试，不等于不同 CPU/GPU、内存和整季长跑均已验收。Mac 上运行 Windows 同款模型也不能替代 Windows 真机性能。100 分钟视频在 5–10 分钟完成的目标尚未达成。Mac/Windows 仍未完成公司代码签名，Mac 尚未公证。
