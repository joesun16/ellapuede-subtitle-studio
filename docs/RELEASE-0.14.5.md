# EllaPuede 字幕提取工具 0.14.5 · 历史候选

正式安装包改由 [0.14.6](RELEASE-0.14.6.md) 提供。本标签不作为最终下载版本。

本版修复同一画面长句在 Windows 韩语 OCR 路线上因单字反复错读而拆为多条的问题。只有连续时间、同一字幕位置和实际争议字形像素一致，程序才把 OCR 反复读出的 A/B/A/B 片段合并。去背景的真实字幕帧会再识别；文字必须来自画面 OCR 实际观察，不能凭词典或剧情补写。真正的换字、数字、否定、标点和空白边界应保留。

用户反馈对应的 120.674 秒视频，原 Windows SRT 有 62 条、6 条短于 0.18 秒。同视频在 Mac 上强制使用 Windows 的 RapidOCR 韩语模型，0.14.4 冷缓存为 56 条，问题句 27.12–29.88 秒拆为 4 条；0.14.5 复用同一帧缓存后为 53 条、1 条极短，问题句为一条且 29.88 秒下一句起点未移动。剩余极短条为片头画面误识别的 `T`；逐字准确率未有全片人工真值，因此不能把条数改善解释为准确率。更多证据见 [质量与性能](QUALITY.md)。

macOS 15 泰语仍走系统 Vision，Windows 与旧版 macOS 使用内置 RapidOCR。Mac Apple Silicon 提供 DMG 或 PKG，Windows x64 提供 Setup.exe；两端版本一致，均为 0.14.5 / build 33。安装包内含运行时和模型，最终用户无需另外下载。SHA-256 与构建核验见 [发布资产清单](RELEASE-ASSETS-0.14.5.json)。两平台尚无公司代码签名，Mac 尚无 Apple 公证。

本公开仓库是干净源码快照，不含内部 Git 历史、用户视频字幕或本机路径。自有代码采用 MIT License，第三方运行时和模型依各自许可证。100 分钟视频在 5–10 分钟处理完成、多机型 Windows 整剧运行和各语言人工逐帧真值仍未验收，保持公测标识。
