# EllaPuede 字幕提取工具 0.14.4 · 开源公测

此源码标签保留为历史记录；正式安装包改由 [0.14.5](RELEASE-0.14.5.md) 提供。

本版从视频画面中提取已经烧录的对白字幕：可导入单集或整剧，手动框选整剧共用的对白区域，指定原字幕语言，处理后自动导出与视频同名的 SRT、ASS 或两者。安装包内置运行时与离线 OCR 模型。

连续字幕现在会在同一画面字带内核对逐帧 OCR 波动：韩语词间空格的暂时变化不再将同一字幕拆开；泰语多读数反复和双行缺读有当前画面的额外复核；孤立的小字符浮层不再轻易混入完整对白。真正变化的短句、标点、数字、否定词和空白边界继续保留。macOS 15 的泰语自动路线改用系统 Vision；Windows 和旧版 macOS 继续使用随包 RapidOCR。

Mac 上同一段 148.821 秒的真实泰语视频，旧版 RapidOCR 冷缓存约 399.76 秒、163 条且 138 条短于 0.18 秒；新版 Vision 冷缓存 109.82 秒、88 条且 25 条短于 0.18 秒。两版 OCR 后端不同，**不能由条数推断文字准确率**，短时错读仍存在。真实韩语 Vision 样片与旧版 23 条文字和 PTS 完全一致；同片 RapidOCR 路线的两处空格波动由 25 条修复到 23 条。英语和中文真实样片亦已回归。完整边界见 [质量与性能](QUALITY.md)。

Mac Apple Silicon 可选 DMG 或 PKG；Windows x64 提供 Setup.exe。安装包版本均为 0.14.4 / build 32。SHA-256 和对应构建核验写入 [发布资产清单](RELEASE-ASSETS-0.14.4.json)。两个平台尚无公司代码签名，Mac 尚无 Apple 公证。
