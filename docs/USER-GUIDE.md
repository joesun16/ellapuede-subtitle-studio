# 使用指南

1. 添加一个视频或整剧文件夹。列表按文件名里的集数自然排序；先确认源文件均已加入。
2. 选中剧组，点击“框选整剧字幕区域”。把框放在**对白字幕的完整两行范围**，可点击“播放”或按空格播放/暂停，也可拖动时间条查看不同镜头。播放预览无声；暂停后再调整框。区域默认应用到这一剧组的各集；需要时可单独调整某集。
3. 选择视频**原有字幕**的语言。自动语言判断目前主要覆盖简中、英语、韩语；泰语及其他语言建议手选。选择语言不会翻译文本。
4. 选择 `SRT`、`ASS` 或同时导出，并选择保存目录。三档处理模式调整资源占用，不改变识别目标。
5. 点击“开始提取”。队列显示当前集和阶段，底部显示整个项目的进度。完成后自动生成与每个视频同名的字幕；可打开输出目录查看。

字幕基于画面 OCR，无法保证每句无误。误识别可在外部字幕编辑器里修改；本工具无需人工校对就能导出。原视频不会被改动。已完成任务可重新导出格式，也可重新处理识别。重做已有同名字幕前，应用会先保留备份。

## 区域怎么选

框住上下两行对白、描边和可能变化的字幕位置；尽量不要包含水印、片头标题、弹幕或招牌。对竖屏剧，字幕可能在画面中下部，不必按固定百分比框。先拖到一段实际有对白的时间点，看预览是否落在框内，再开始整剧。

## 哪些语言可用

手选项包括英语、简体中文、繁体中文、中英双语、日语、韩语、泰语、西班牙语、法语、德语、葡萄牙语和意大利语。不同语言与不同识别后端可能产生不同结果；选择准确的原字幕语言通常比自动判断更可靠。泰语当前没有真实剧集人工真值评估。

## 遇到问题

- **进度暂时为 0：** 首次启动需要初始化离线 OCR 进程及视频探测，查看当前阶段文字。持续无变化时记录应用版本、系统、视频时长、语言、模式和等待时间，并在 Issues 中报告。
- **字幕混入画面文字：** 重新框选更窄的对白区域，再重新处理。
- **同一句拆成多条：** 请提供可公开的合成复现片段、对应时间点和旧/新输出；不要上传未授权的剧集视频或字幕。
- **机器发热、内存不足：** 选用更节省资源的模式，减少同时运行的其他程序。不同硬件的实际速度尚未完整验收。
